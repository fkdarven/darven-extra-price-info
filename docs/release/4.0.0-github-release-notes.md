Esta release reconcilia o histórico do GitHub com a versão **4.0.0**, publicada no WordPress.org em **26/08/2026**. A publicação no GitHub ocorre na data exibida nesta release.

## Novidades

- Nova identidade pública: Darven Preços Parcelados, anteriormente Darven Múltiplos Preços Informativos.
- Novo painel administrativo em React, com configurações reorganizadas por tarefa e feedback de carregamento, validação e salvamento.
- API REST autenticada para configurações globais e opções por produto.
- Editor visual para ordenar preço original, preço à vista e preço parcelado.
- Controles de apresentação, posicionamento e compatibilidade com efeito real e sanitizado na vitrine.
- Janela acessível de parcelas, responsiva, com navegação por teclado, controle de foco, tecla Esc e suporte a múltiplos produtos na mesma página.
- Opções modernizadas no editor de produtos, incluindo produtos variáveis e configurações herdadas.
- Migração não destrutiva das configurações e metadados da linha 3.x, preservando os dados e espelhos legados existentes.
- Integração automática e segura com YITH WooCommerce Dynamic Pricing and Discounts, com fallback para os preços do WooCommerce.
- Tradução para português do Brasil no PHP e nas duas aplicações administrativas.
- Correções de persistência, cálculos de juros, limites de parcelas, estados sem juros, salvamentos concorrentes e validação das requisições REST.
- Compatibilidade validada com WordPress 7.1 e WooCommerce 11.0.0.
- Requisito mínimo de PHP 8.0; a versão 3.3.1 permanece disponível no WordPress.org para instalações com PHP 7.4.

## Compatibilidade e atualização

Requer WordPress 5.0 ou superior, PHP 8.0 ou superior e WooCommerce. A QA histórica incluiu instalação limpa, atualização exata da versão 3.3.1, preservação de configurações e metadados, telas administrativas e navegação por teclado no popup.
