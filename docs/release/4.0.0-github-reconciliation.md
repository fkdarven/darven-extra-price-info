## Passos preparados — executar somente após nova autorização

### 1. Preflight de leitura e validação

```sh
set -eu
release_repo=fkdarven/darven-extra-price-info
release_target=75111897e025f175d5fd521aef14c6fc54b6c3a7
release_zip=/home/darven/seox/darven-extra-price-info/dist/darven-extra-price-info-4.0.0.zip
test -z "$(git status --porcelain)"
test "$(git remote get-url origin)" = "https://github.com/$release_repo.git"
git fetch origin main --tags
git cat-file -e "$release_target^{commit}"
test "$(git rev-parse "$release_target^{tree}")" = 9960c898832b83d8bec5d6c2525f30eb0337ec95
gh api "repos/$release_repo/branches/main" --jq '.commit.sha'
release_tag_refs=$(git ls-remote --tags origin refs/tags/v4.0.0 'refs/tags/v4.0.0^{}')
test -z "$release_tag_refs"
test -z "$(git tag --list v4.0.0)"
release_count=$(gh api "repos/$release_repo/releases?per_page=100" --paginate --slurp --jq '[.[][] | select(.tag_name == "v4.0.0")] | length')
test "$release_count" = 0
test -f docs/release/4.0.0-github-release-notes.md
test -f "$release_zip"
test "$(wc -c < "$release_zip")" -eq 184726
sha256sum --check <<'SHA256'
dfb433bb62597fe4b9d5c598566cb4dd831b9748a7462e465e2b6f842a4d53e5  /home/darven/seox/darven-extra-price-info/dist/darven-extra-price-info-4.0.0.zip
SHA256
```

Se `main`, tags ou releases mudaram desde a verificação, revisar o estado com o mantenedor antes de prosseguir. Os testes de ausência param diante de uma tag/release existente; não apagar, mover nem sobrescrever uma publicação existente. A consulta autenticada e paginada considera todas as releases retornadas, incluindo drafts acessíveis ao mantenedor.
